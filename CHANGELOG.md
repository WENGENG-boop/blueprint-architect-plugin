# Changelog

All notable changes to this project are documented here.

## 0.2.0 - 2026-08-15

- Add the versioned `BlueprintSpec` contract with reference, evidence, secret, and path validation.
- Replace named-stack checks with extensible capability rules and complete relationship-edge coverage.
- Require primary evidence for version-sensitive verified compatibility and preserve unknown technologies as unverified.
- Generate PRD-derived module trees, concrete interface contracts, traceability, compatibility, evidence, deployment, and test documents.
- Replace the legacy generator CLI with a `BlueprintSpec` JSON input contract.
- Preserve selector decisions in Plan mode and numbered prose decisions elsewhere.

## 0.1.0 - 2026-08-14

- Publish the Blueprint Architect Codex marketplace and plugin.
- Add PRD interpretation and structured decision-selector workflow.
- Add compatibility and module-type resources as valid YAML.
- Add non-destructive, path-safe blueprint generation.
- Add explicit optional GitHub-search result states.
- Add cross-platform tests and release validation.
