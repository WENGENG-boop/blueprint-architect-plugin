# Security policy

## Supported versions

Security fixes are provided for the latest released version on the default branch.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature for this repository. Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not publish credentials, private PRDs, tokens, or exploit details in a public issue.

If private reporting is unavailable, open a public issue containing no sensitive details and ask the maintainer for a private reporting channel.

The maintainer will acknowledge a complete report when available, assess severity, and coordinate disclosure after a fix is ready. No response-time guarantee is made for this community-maintained project.
